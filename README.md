# 솔버 시뮬레이터

스왑 · 브릿지 · 크로스체인 스왑을 앱 화면 안에서 직접 해 보면서, 그 뒤에서 **솔버**가 무엇을 푸는지 배우는 설명용 시뮬레이션이다.

**→ [열어 보기](https://znwxyz.github.io/radius-solver-sim/)**

## 어떻게 돌아가나

지갑을 연결해 내가 가진 체인과 토큰을 확인하고, 할 거래를 고르고, 직접 설정해서 보낸다.
거래가 끝나면 그 뒤에서 솔버들이 무엇을 따져봤는지, 유저 입장에서 뭐가 좋은지 이어서 본다.

```
지갑 연결 → 내 자산 → 무엇을 해 볼까 → 거래 설정 → 처리 중 → 거래 완료
  → 솔버들이 하는 고민 → 유저 입장에서 좋은 점
```

- 가려진 라벨을 눌러 개념을 하나씩 연다(체인 → 토큰 → 잔액).
- 고른 거래에 맞지 않는 설정은 막히면서 왜 막혔는지 알려 준다.
- 체인·토큰 색은 "이게 무엇인가", Radius 색은 "지금 눌러야 할 곳"으로 역할이 나뉘어 있다.

## 이 화면이 말하지 않는 것

- 참여·경쟁·정산 방식은 프로토콜마다 다르다.
- 같은 체인 스왑이라고 솔버가 없는 것이 아니다. 솔버를 거칠지 말지는 거래 종류의 성질이 아니라 쓰는 서비스가 정하는 경로다.
- 유저는 솔버를 고를 수 없다. 여러 솔버 중 누가 실행하게 되는지는 프로토콜의 규칙이 정한다.
- 거래 체결이 반드시 보장되는 것은 아니다. 조건에 맞는 참여자가 없으면 거래가 성립하지 않는 때도 있다.
- **수치는 전부 예시다.** 실제 거래 앱이 아니라 설명을 위해 만든 화면이다.

## 만듦새

설치도 빌드도 없는 정적 파일이다. `index.html` 을 열면 그대로 돈다.
바깥에서 받아 오는 것은 폰트(DM Sans · DM Mono · Pretendard)뿐이고, 없으면 시스템 폰트로 떨어질 뿐 화면은 그대로 작동한다.

체인·토큰 아이콘은 각 프로젝트의 공식 로고다.
